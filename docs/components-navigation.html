Breadcrumb Molecule components/navigation.css

  1. Home
  2. Repair café
  3. What we can repair

Use

  • On pages two or more levels deep (2.4.8).

Don't

  • Link the current page.
  • Use it inside a form flow; use a back link.

Pagination Molecule components/navigation.css

  • Previous page
  • 1
  • 2
  • 3
  • …
  • 9
  • Next page
  • NextElectrical safety

Use

  • Numbered for lists and search results.
  • --block for previous / next between pages of a guide.
  • Show first, last and the pages around the current one.

Don't

  • Use infinite scroll: the footer becomes unreachable.

In-page navigation Molecule components/navigation.css

On this page

  • Actions
  • Forms
  • Feedback

Use

  • Long pages with three or more h2s.
  • --sticky keeps it in view on wide screens; contour.js marks the section in view.

Don't

  • Use it on short pages.

Step indicator Molecule components/navigation.css

Step 2 of 4

  1. Item
  2. Date
  3. Contact
  4. Check

Use

  • Linear forms with 3 to 6 steps.
  • The text "Step 2 of 4" is the indicator; the bars repeat it.

Don't

  • Use it when steps can be done in any order; use a task list.

Task list Organism components/navigation.css

  • Item to repairCompleted
  • Contact detailsSo we can confirm your slotIncomplete

Use

  • Long transactions people do over several sessions, in any order.
  • Status in words.

Don't

  • Use it for a short linear form.
