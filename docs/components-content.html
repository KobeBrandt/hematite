Prose and lists Organism components/content.css

Before your visit

Clean the item and bring every part, including chargers and remotes.

  • Unplug it the night before.
  • Write down what happens when it breaks.
  1. Arrive 5 minutes early.
  2. Sign in at the desk.

Use

  • .prose around long-form content.
  • .list--bullet, --number, --ruled, --spaced.

Don't

  • Nest lists more than two levels deep.

Icons sit on the text baseline and take its colour.

Use

  • <svg class="icon"><use href="../icons/hematite-icons.svg#check"/></svg>
  • aria-hidden="true" next to a text label.
  • --m 1.5rem and --l 2.25rem.

Don't

  • Use an icon alone without an accessible name.
  • Use icons as decoration in running text.

Drawing rules

  • 24-unit grid, 1.75 stroke.
  • Round caps and joins, no fills.
  • 39 icons, about 4 KB.

Bar chart Organism components/content.css

Use

  • Horizontal bars with the value written on each bar.
  • A <dl> or table underneath, so the numbers are always readable.
  • Highlight one bar, the one the caption is about.

Don't

  • Use colour as the only way to tell series apart.
  • Use a pie chart: lengths are easier to compare than angles.

Data visualisation

  • Start bars at zero.
  • Write the conclusion in the caption.
  • Offer the table for anything complex.
