Show and hide

Native elements first. Hidden content must be content people can do without. css/components/interactive.css

Disclosure Molecule components/interactive.css

When is the café open?

Every Saturday from 9am to 1pm.

Can I come without booking?

Yes, if there is a free slot. Booked visitors go first.

Help with the model number

Look for a sticker on the bottom or back of the item.

Use

  • Native <details>: keyboard, state and screen reader support for free.
  • --plain for "Help with this question" inside a form.

Don't

  • Hide information every user needs.
  • Rebuild it with divs and ARIA.

Accordion Organism components/interactive.css

Electrical

Lamps, toasters, radios, kettles.

Textiles

Clothes, bags, curtains.

Bikes

Brakes, gears, punctures, lights.

Use

  • A heading in each summary, so the page outline stays intact.
  • "Show all sections" button (hematite.js reveals it).
  • name="…" on the details for one-open-at-a-time.

Don't

  • Use it for content most people need; then show it.

Tabs Organism components/interactive.css

  • Opening hours
  • Address
  • Parking

Opening hours

Saturdays, 9am to 1pm.

Address

Kerkstraat 12, 9000 Gent.

Parking

Free bike parking in front; car park 200 m away.

Use

  • Links and panels in HTML; hematite.js turns them into ARIA tabs with arrow keys.
  • Without JS every panel shows.

Don't

  • Use tabs for content people want to compare.
  • Use them as page navigation.

Dialog Organism components/interactive.css

Cancel this booking?

Your slot on Saturday 14 November will go to the next person on the waiting list.

Use

  • Native <dialog> with showModal(): focus, Escape and the inert page come free.
  • For a confirm or a very short form.

Don't

  • Open dialogs without people asking.
  • Put long forms in a dialog; give them a page.

Tooltip Molecule components/interactive.css

Print booking

Use

  • A short name for an icon button, on hover and focus.
  • Escape hides it (1.4.13).

Don't

  • Put essential information or links in a tooltip.

Popover Molecule components/interactive.css

Show

Use

  • Native popover attribute: light dismiss and Escape are free.
  • Sits under its button where anchor positioning is supported.

Don't

  • Use it for content that must stay visible.
  • PreviousNavigation components
  • NextPage components
