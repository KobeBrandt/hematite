Site header and navigation Organism components/page.css

Repair Café
Menu
  • Book
  • Workshops
  • Help

Use

  • Same links, same order on every page (3.2.3).
  • aria-current="page" on the active link.
  • details.nav-menu collapses the links behind Menu on small screens. With contour.js, on phones the Menu button floats at the bottom right, within thumb reach, and the links open as a sheet from the bottom edge; Escape or a tap outside closes it. Without JS it is an open list in the header.
  • Keep the header to one slim row on phones and do not make it sticky there.

Don't

  • Hide primary links behind a menu on desktop.
  • Use more than about seven top-level items.

Modifiers

  • --sticky sticks it to the top

Cookie banner Organism components/page.css

Cookies on this site

We use some essential cookies to make this site work. We would also like to set analytics cookies to understand how you use it.

View cookies

You have accepted analytics cookies. You can change this at any time on the cookies page.

You have rejected analytics cookies. You can change this at any time on the cookies page.

Use

  • Accept and reject are equal buttons.
  • First in the page after the skip link; no consent cookies until people choose.
  • Listen for the contour:cookies event to load analytics.

Don't

  • Use a modal that blocks the page.
  • Make "accept" the only bright button.

Sticky action bar Organism components/page.css

Use

  • Long edit pages where the save button would scroll away.
  • Add .has-sticky-bar to <body> so focus is never hidden behind it (2.4.11).

Don't

  • Use it on short forms.
