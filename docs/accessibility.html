Accessibility

Target: WCAG 2.2 level AA. The system handles what CSS can handle. Some criteria depend on your HTML and content, so they are listed as yours.

WCAG 2.2 AA coverage
CriterionWhoHow
1.4.3 Contrast (minimum)SystemEvery text colour is 6.2:1 or higher on its background, in both themes.
1.4.11 Non-text contrastSystemControl edges are 3.5:1 or more in both themes; hairlines are decorative and never the only edge of a control. Checked and selected states add a thicker edge or a raised shape, not just colour.
1.4.1 Use of colourSystemLinks underlined, errors prefixed with "Error", alerts and badges carry a word, disabled is dashed, the current item is a graphite key and bold, or carries a green light next to bold text.
1.4.4 / 1.4.10 / 1.4.12 Resize, reflow, text spacingSystemrem units, em breakpoints, fluid headings, wrapping layouts, tables scroll in a box.
1.4.13 Content on hover or focusSystemTooltips show on hover and focus, stay while hovered, close with Escape.
2.4.7 Focus visibleSystemOne focus style for everything: a 2px gunmetal outline 2px clear of the element (8.8:1 / 11.4:1 on the page), plus a soft halo.
2.4.11 Focus not obscuredSystemscroll-padding keeps focus clear of sticky headers and the sticky action bar.
2.5.7 Dragging movementsSystemThe range slider always has an output, and the docs tell you to offer a text input.
2.5.8 Target size (minimum)SystemControls are 2.75rem tall; inline links in rows 1.5rem.
2.3.3 / reduced motionSystemAll transitions and animations stop under prefers-reduced-motion.
Forced coloursSystemEvery component file has a forced-colors block, so borders and current states survive Windows high contrast.
4.1.3 Status messagesSystemToasts, character counts, password toggles and table sorting announce through polite live regions.
2.4.1 Bypass blocksYouPut .skip-link first in <body>, pointing at <main id="main">.
1.1.1 Non-text contentYouWrite alt that says what the image shows; alt="" for decoration.
1.3.1 / 2.4.6 Structure, headings, labelsYouLandmarks, one h1, no skipped levels, a label for every field.
3.1.1 / 3.1.2 LanguageYou<html lang="nl">, and lang on parts in another language.
3.3.1 / 3.3.3 ErrorsYouUse the error summary and .field__error, set aria-invalid, and say how to fix it.
3.3.8 Accessible authenticationYouAllow paste and password managers; use the password input's Show button.
2.1.1 KeyboardYouUse native elements. Test every page with Tab, Shift+Tab, Enter, Space and Escape.
