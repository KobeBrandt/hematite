Browser support

The last two versions of Chrome, Edge, Firefox and Safari (desktop and mobile). Hematite uses Baseline CSS: features that work in all four. Features that are still rolling out are enhancements; without them the page works and looks the same, it just moves less. See Modern CSS for the list.

Install

Copy the css/, js/ and icons/ folders into your project, or add the repository as a git submodule. There is no build step and nothing to install.

Start a page

<!doctype html>
<html lang="nl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page name · Site name</title>
  <link rel="stylesheet" href="../css/hematite.css">
  <script src="../js/hematite.js" defer></script>  <!-- optional -->
</head>
<body>
  <a class="skip-link" href="#main">Skip to content</a>
  <header class="site-header">…</header>
  <main id="main" tabindex="-1" class="container page stack">
    <h1>Page name</h1>
  </main>
</body>
</html>

Cascade layers

Hematite puts every file in a layer: hematite.tokens < base < layout < components < utilities < print. Your own CSS, outside any layer, always wins, whatever its specificity. No !important needed.

The flip side: any unlayered reset also wins. If a CMS, framework or host page sets body { background: #fff } without a layer, dark mode breaks. Put that reset in a layer declared before Hematite (@layer reset, hematite.tokens, …), or restate the page ground unlayered: body { background: var(--color-bg); color: var(--color-ink); }.

Make a theme

Override tokens, not components. Give each colour a light and a dark value with light-dark(), and keep every text colour at 4.5:1 or above on --color-bg in both.

:root {
  --color-accent: light-dark(oklch(55% 0.17 150), oklch(80% 0.14 150));   /* --color-on-accent on it must stay 4.5:1+ */
  --color-link: light-dark(oklch(45% 0.2 300), oklch(80% 0.12 300));
  --radius-l: 2rem;   /* rounder shells */
}

Pin a theme

Dark follows the OS setting. Set data-theme="light" or "dark" on <html> to force one. Because the tokens use light-dark(), one block can have its own theme too: add theme-dark or theme-light to it.

Right to left

Components use logical properties (margin-inline-start, border-inline-start), so <html dir="rtl"> mirrors the layout. Arrows and the select chevron flip too.

Versions and changes

Hematite follows semantic versioning. Breaking changes (a renamed class, a removed token) bump the major number. See CHANGELOG.md for every release and CONTRIBUTING.md for how to propose a component: a real need, a "Use" and "Don't" list, and an accessibility test before it ships.
